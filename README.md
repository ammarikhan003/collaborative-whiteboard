# Collaborative Whiteboard

A real-time collaborative drawing application where multiple users can draw on the same canvas simultaneously from different devices.

## Features

- Real-time drawing collaboration using WebSockets
- Colour picker for stroke colour
- Brush size adjustment
- Touch screen support for mobile devices
- Clear canvas functionality
- User count display

## Technologies Used

- **Frontend**: HTML5 Canvas API, JavaScript
- **Backend**: Node.js, Express.js
- **Real-time Communication**: Socket.IO
